# ☕ Projeto Java - Curso Alura

Projeto desenvolvido durante o curso de Java da **Alura**, focado em praticar os conceitos iniciais da linguagem e a lógica de programação.

---

## 📌 O que foi praticado neste código:

- **Sintaxe e Variáveis:** Manipulação de tipos de dados (`int`, `double`, `String`).
- **Estruturas de Controlo:** Uso de condicionais (`if/else`) e laços de repetição (`while` / `for`).
- **Orientação a Objetos (se aplicável):** Criação de classes, métodos e atributos.

---

## 🛠️ Tecnologias e Ferramentas:

* **Linguagem:** Java
* **IDE:** VS Code / Eclipse / IntelliJ IDEA
* **Plataforma de Ensino:** Alura

---

## 🚀 Como Executar o Projeto

1. Baixe ou clone este repositório.
2. Abra o projeto na sua IDE de preferência (VS Code, Eclipse, IntelliJ, etc.).
3. Execute o arquivo `Desafio.java`.
